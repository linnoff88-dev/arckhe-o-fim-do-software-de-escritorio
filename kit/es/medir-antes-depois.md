# Guía de la ficha de medición

Archivo CSV común: [medir-antes-depois.csv](../medir-antes-depois.csv).

Cada fila corresponde a una ejecución. Los minutos deben incluir la revisión, las correcciones y el seguimiento; no omitas ninguno de estos tiempos. No inventes mediciones.

| Encabezado | Significado |
|---|---|
| caso | Caso evaluado. |
| data | Fecha de la ejecución. |
| modo | Modo utilizado. |
| volume | Volumen de elementos procesados. |
| complexidade | Complejidad del caso. |
| busca_min | Minutos dedicados a la búsqueda. |
| preparacao_min | Minutos dedicados a la preparación. |
| ia_min | Minutos de uso de la IA. |
| revisao_min | Minutos dedicados a la revisión. |
| correcao_min | Minutos dedicados a las correcciones. |
| acompanhamento_min | Minutos dedicados al seguimiento. |
| erros | Errores encontrados. |
| qualidade_aceita | Indica si la calidad fue aceptada. |
| resultado_observado | Resultado observado. |
